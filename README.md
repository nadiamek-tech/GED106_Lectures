# GED 106 · Smart Decisions: Data Literacy & Visualization

Narrated, visual lectures for GED 106 (Canadian University Dubai), Weeks 1–8 plus a midterm review page. Plain static HTML with no build step.

- `index.html` is the course map ("Start here")
- `week-01.html` … `week-08.html` are the lectures, each with its lab
- `review.html` is the midterm review
- `assets/` holds the shared styles and lecture engine (shared with GED 102)

Open `index.html` in a browser, or serve the folder with GitHub Pages.
