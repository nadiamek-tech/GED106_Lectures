# GED 106 · Smart Decisions: Data Literacy & Visualization

Course site: one link for students. Plain static HTML, no build step.

- `index.html` home: Lectures · Labs · Exams, help agents, FAQ, calendar, CLOs and grades, submissions
- `lectures.html`, `labs.html`, `exams.html` the three sections; `week-XX.html`, `lab-XX.html` the pages
- `assets/course-info.js` **the only file to edit**: links (form, booking, portal, Moodle), dates, assessments, calendar
- `assets/portal.js`, `assets/portal.css` shared course portal (same files in every course repo)
